# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Tools Used
- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## Project Files
- `index.html` — website content and structure
- `style.css` — responsive styling and layout
- `README.md` — project documentation

## Deployment Steps
1. Created a GitHub repository for the project.
2. Added the HTML and CSS files.
3. Committed and pushed the files to the `main` branch.
4. Enabled GitHub Pages in **Settings → Pages**.
5. Selected the `main` branch and `/ (root)` folder.
6. Opened the published website using the URL provided by GitHub Pages.

## Features
- Responsive developer portfolio
- About section
- Technical skills
- Featured projects
- Contact section
- Custom CSS styling
